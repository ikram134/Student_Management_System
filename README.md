Student Management System
A console-based Student Management System developed using the C programming language.

About the Project
This project allows users to manage student records through a simple menu-driven interface. It uses structures and binary file handling to store and manage student information.

Features
Add new students
Display all students
Search for students by ID
Update student information
Delete student records
Technologies Used
C Programming Language
Structures
File Handling
Binary Files (fread and fwrite)
Data Storage
Student records are stored in a binary file named students.dat.

How to Run
Clone this repository.
Open main.c using a C compiler or IDE.
Compile and run the program.
Select an option from the menu to manage student records.
